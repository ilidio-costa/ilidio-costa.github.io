## Featured Projects

### 1. Parameter Optimization of NiTi for L-PBF (Master's Thesis)
**Objective:** Developed a stable process for printing Nitinol (NiTi) shape memory alloys.
* **Method:** Used Taguchi DoE and Response Surface methodologies to minimize experimental iterations.
* **Result:** Achieved < 0.07% porosity and validated phase composition for shape memory effects.
